## 核心设计要点

### 用户认证
- 手机号验证码登录为主，邮箱密码为备选
- 第三方 OAuth (微信/Apple/Google) 通过 `wechat_openid` / `apple_user_id` / `google_openid` 绑定
- 双 Token 机制: Access Token 7天, Refresh Token 30天
- 密码使用 bcrypt (≥12轮) 加盐哈希

### 翻译记录
- 支持游客记录 (user_id=NULL)
- FULLTEXT 索引支持原文/译文搜索
- `sync_status` 追踪云端同步状态
- 软删除 (`is_deleted`) 保留数据可恢复

### 云端同步
- 增量同步: 通过 `updated_at` 时间戳比对
- 冲突检测: `sync_logs.conflict_count` 记录冲突数
- 5 类同步数据: history / favorite / settings / profile / offline_pack

### 安全
- 验证码频率限制: 同一目标60秒1次, 每天10次
- 敏感操作需短信二次确认
- 账户注销30天冷静期 (`deleting` 状态)
