## 1. 产品概述

### 1.1 产品定位

**实时语音翻译**是一款面向课堂场景的语音记录与翻译工具。通过设备麦克风实时捕获教授讲课语音，利用 ASR 将外语授课转为文字，并即时翻译为学生母语。学生可在听课过程中**一键收藏关键知识点**，课后导出为双语笔记复习。产品核心解决留学生"听不懂外语授课、来不及记笔记"的痛点。

### 1.2 产品愿景

> 让每一位留学生不再因语言障碍而错过课堂上的任何一个知识点。

### 1.3 核心价值主张

| 维度 | 价值 |
|------|------|
| **实时转录** | 教授讲课实时转文字 + 翻译，延迟 < 1.5 秒 |
| **双语对照** | 原文 + 译文同屏上下对照，像字幕一样自然 |
| **一键收藏** | 听到关键内容一键标记，自动保存为知识点卡片 |
| **课后复习** | 完整课堂记录 + 收藏集，支持导出笔记 |
| **持续聆听** | 免操作自动断句翻译，学生专注听讲即可 |

### 1.4 与 LiveTrans（摄像头翻译）的关系

| 维度 | LiveTrans（视觉） | LiveTrans Voice（语音） |
|------|------------------|------------------------|
| 输入方式 | 摄像头 → OCR | 麦克风 → ASR |
| 适用场景 | 菜单/路牌/文件 | 对话/会议/课堂 |
| 输出形式 | 画面叠加卡片 | 对话气泡列表 |
| 账户体系 | 共用 | 共用 |
| 翻译引擎 | 共用 | 共用 |

## 2. 目标用户与场景

### 2.1 用户画像

#### 画像 A：留学生（★核心用户）
- **年龄**：18-30 岁
- **特征**：在国外大学就读，外语授课听不懂或只能听懂 60-70%，记笔记更困难
- **痛点**：教授语速快、专业术语多，纯靠听力跟不上；课后借同学笔记也不一定能借到
- **期望**：打开 App 放在课桌上，自动识别教授的讲课内容并翻译成中文，看到重要内容点一下就能收藏

#### 画像 B：国际高中/预科学生
- **年龄**：15-19 岁
- **特征**：刚出国，语言基础薄弱，上课基本听不懂
- **痛点**：听不懂就不敢提问，形成恶性循环，成绩下滑
- **期望**：实时看到老师讲的内容翻译，课后回看复习

#### 画像 C：访问学者/交换生
- **年龄**：25-40 岁
- **特征**：短期出国交流，需要快速适应外语学术环境
- **痛点**：语言水平尚可但学术词汇不足，研讨会、讲座跟不上
- **期望**：专业术语翻译准确，支持收藏重点内容用于论文写作

### 2.2 核心使用场景

| 优先级 | 场景 | 说明 |
|--------|------|------|
| **P0** | **课堂讲座记录** ★核心 | 教授讲课全程录音 → 实时识别 → 翻译 → 学生看到双语字幕流，关键句一键收藏 |
| P0 | 小组讨论/Tutorial | 小班讨论课，多人发言实时翻译，标记讨论要点 |
| P1 | 学术会议/研讨会 | 长时间主题演讲，专业术语翻译，导出演讲纪要 |
| P1 | 课后复习回看 | 回看历史课堂记录，按收藏点快速定位重点 |
| P2 | 视频课程学习 | Coursera/YouTube 外语课程实时字幕翻译 |

### 2.3 典型用户故事

> **作为**一个在德国慕尼黑工业大学读机械工程的中国留学生，
> **我希望**上课时把手机放在桌上自动识别教授的德语讲课并实时显示中文翻译，
> 遇到重点内容点一下就能收藏，
> **以便**我课后能快速回顾关键知识点，不用借同学笔记也能跟上课程进度。

> **作为**一个在美国读 MBA 的印度学生，
> **我希望**在案例讨论课上看到教授和同学们发言的实时翻译和原文，
> 并能标记关键案例数据和结论，
> **以便**我能在写论文时引用准确的信息来源。

> **作为**一个在日本语言学校的初学者，
> **我希望**录下老师的日语讲解并看到中日双语对照，
> 同时把新学的单词和语法点收藏起来，
> **以便**我每天能复习当天学到的重点词汇和表达。

## 4. 功能详细说明

### 4.1 语音录制与识别（P0 ★核心功能）

#### 4.1.1 功能描述

用户点击录音按钮后，设备麦克风开始采集音频。采集到的音频流实时发送到 ASR 引擎，引擎返回识别文本。系统自动检测用户是否说完一句话（VAD），然后触发翻译。

#### 4.1.2 交互流程

```
[点击录音按钮] → [麦克风开始采集]
    → [音频流 → ASR引擎] → [实时返回识别文本 (流式)]
    → [检测到语句结束 (VAD静音≥1.5秒)] → [触发翻译]
    → [译文出现在原文下方] → [继续聆听下一句]
    → [点击停止] → [录音结束，生成对话记录]
```

#### 4.1.3 录音模式

| 模式 | 触发方式 | 适用场景 | 优先级 |
|------|---------|---------|--------|
| **按键说话** | 按住按钮说话，松手结束 | 短问短答，可控度高 | P0 |
| **持续聆听** | 点击开关，自动断句、自动翻译 | 长时间对话/会议 | P1 |
| **单人聆听** | 只听对方说话并翻译（自己不录） | 听课/听演讲 | P1 |

#### 4.1.4 录音状态

| 状态 | 界面表现 | 触发条件 |
|------|---------|---------|
| **待机态** | 圆形录音按钮，脉冲动画 | 未开始录音 |
| **录音中** | 波形动画 + 绿色呼吸光效 + 计时器 | 麦克风采集音频中 |
| **识别中** | 原文区显示"..."逐步出现文字（流式） | ASR 处理中 |
| **翻译中** | 译文区显示"..."加载 | 翻译请求处理中 |
| **完成** | 原文 + 译文稳定显示，自动加入气泡列表 | 翻译结果返回 |
| **暂停** | 按钮变灰 + "已暂停"标签 | 用户手动暂停 |
| **错误** | 红色脉冲 + "点击重试" | ASR/翻译失败 |

#### 4.1.5 波形可视化

- 录音时显示实时音频波形（上下对称）
- 波形颜色跟随品牌主色 `#4A90D9`
- 静音段波形低平，说话段波形高振
- 持续聆听模式下，两句话之间显示静音分隔线

### 4.2 双语字幕展示（P0 ★核心功能）

#### 4.2.1 课堂字幕布局

课堂场景下，页面采用**上下分区字幕流**设计——教授说话内容实时以双语字幕形式从底部向上滚动，类似视频弹幕的阅读体验。

```
┌─────────────────────────────────┐
│  ← 过往句（可向上滚动查看）      │
│                                 │
│  … In the 18th century, the     │
│  Industrial Revolution began …  │  ← 原文 (灰色，已确认)
│  … 18世纪，工业革命始于英国…     │  ← 译文 (绿色，已确认)
│  ─────────────────────────────  │
│  The steam engine played a      │  ← 原文 (黑色加粗，当前句)
│  crucial role in this process.  │
│  蒸汽机在这一过程中发挥了关键作用。│  ← 译文 (大字，绿色加粗)
│  ─────────────────────────────  │  ← 收藏按钮 ★
│                                 │
│  正在聆听... ▓▓▓▓▓▓▓▓▓▓        │  ← 波形 + 状态
└─────────────────────────────────┘
```

#### 4.2.2 展示规则

| 元素 | 样式 | 说明 |
|------|------|------|
| **当前句原文** | 大字 22px，`#1A1A1A` 加粗，左对齐 | 正在识别/刚识别完成的句子 |
| **当前句译文** | 大字 20px，`#4CAF50` 加粗，左对齐 | 翻译结果，最醒目的部分 |
| **历史句原文** | 小字 15px，`#8B8B8B`，左对齐 | 已确认的过往句子，可滚动回看 |
| **历史句译文** | 小字 14px，`rgba(76,175,80,0.7)`，左对齐 | 褪色处理，减少视觉干扰 |
| **收藏标记** | ★ 黄色星标 `#FF9800`，句首 | 已收藏的句子在前面显示星标 |
| **时间戳** | `#8B8B8B` 小字，每5分钟插入一次 | 方便课后定位 |

#### 4.2.3 流式识别展示

- ASR 返回部分结果时，当前句原文**逐字出现**
- 识别稳定后文字由斜体变正体
- 翻译完成后，译文在原文下方**平滑展开**（200ms ease-out）
- 每当新的句子确认，旧句子自动上移进入历史区
- 历史区最多保留 200 条句子，超出自动清理最早条目

#### 4.2.4 收藏按钮

- 每条译文右侧有一个**星标按钮 ☆**
- 点击后变为 **★ 已收藏**（橙色 `#FF9800`，200ms 弹性缩放动画）
- 收藏时弹出 Toast："已收藏到知识卡片"
- 支持撤销：再次点击取消收藏

### 4.3 收藏与标记（P0 ★核心功能）

#### 4.3.1 功能描述

学生在听课过程中，听到重点内容（如"考试重点"、"公式"、"定义"等）可以一键收藏。系统将当前句子及其翻译保存为**知识卡片**，包含原文、译文、时间戳和可选标签。

#### 4.3.2 收藏类型

| 类型 | 图标 | 颜色 | 用途 |
|------|------|------|------|
| **重要** | ⭐ 星标 | `#FF9800` 橙 | 考试可能会考的重点内容 |
| **疑问** | ❓ 问号 | `#4A90D9` 蓝 | 没听懂、需要课后查的 |
| **考点** | 🎯 靶心 | `#EF4444` 红 | 教授明确说"会考"的内容 |
| **定义** | 📖 书本 | `#8B5CF6` 紫 | 术语定义、概念解释 |

#### 4.3.3 收藏流程

```
[听课中，系统持续翻译]
    → 教授讲到重点 → 学生点击译文旁的 ☆
    → 弹出标签选择: ⭐重要 / ❓疑问 / 🎯考点 / 📖定义
    → 选择标签 (或直接默认"重要")
    → 星标变为橙色 ★ → Toast: "已收藏"
    → 该句出现在"我的收藏"列表中
```

#### 4.3.4 收藏列表

- **入口**：录音界面顶部工具栏的"收藏"图标
- **展示**：按时间顺序排列，每条显示原文 + 译文 + 标签 + 收藏时间
- **筛选**：按标签类型筛选（全部/重要/疑问/考点/定义）
- **点击**：跳转到课堂记录中该句的位置，可重新播放对应录音片段
- **导出**：选中多条收藏 → 导出为 TXT/Markdown 笔记

#### 4.3.5 课后复习

- 一堂课结束后，生成"课堂摘要"：
  - 总录音时长 / 总句子数
  - 收藏知识点数量 / 按标签分类
  - 专业术语列表
- 学生可一键导出：
  - 全部课堂记录（双语对照）
  - 仅收藏知识点（Markdown 格式，方便导入 Notion/Obsidian）
  - PDF 笔记（含课程名、日期、收藏点标注）

### 4.4 录音控制（P0/P1）

#### 4.4.1 课堂录音模式（P0）

课堂场景默认使用**持续聆听模式**，学生进入教室后点击开始即可：

```
[点击开始] → 持续聆听（后台运行，可锁屏）
    → 检测到教授说话 → ASR 流式识别
    → 静音 ≥1.5s → 自动断句 → 触发翻译
    → 当前句双语显示 → 旧句上移进入历史区
    → 无人说话 ≥30s → 进入低功耗待机（保持麦克风监听）
    → 检测到说话 → 立即恢复识别
[点击停止] → 生成课堂记录 → 弹出本次课堂摘要
```

#### 4.4.2 录音控制

| 操作 | 触发 | 说明 |
|------|------|------|
| 开始/停止 | 点击中央录音按钮 | 全程一次开始、一次停止 |
| 暂停/恢复 | 点击暂停按钮 | 课间休息时暂停 |
| 锁屏继续 | 自动 | 锁屏后后台继续录音和翻译 |

#### 4.4.3 安静环境优化

课堂场景特点：单人长时间持续发言，环境相对安静。系统针对此场景优化：
- 提高远场语音识别灵敏度（手机可放在课桌距离 1-3 米）
- 教室回声抑制
- 降低 VAD 误断率（教授思考时的长停顿不误断句）

### 4.4 语言设置（P0）

与 LiveTrans（摄像头版）共享语言配置：

- **源语言**：默认"自动检测"(根据语音特征自动识别语种)
- **目标语言**：默认用户系统语言
- **快速交换**：点击 ⇄ 按钮交换源/目标语言
- **自选语种**：50+ 语言可选
- **ASR 语种限制**：部分语种不支持离线语音识别，需网络

### 4.5 课堂记录与回看（P1）

#### 4.5.1 课堂记录

- 每次"开始录音 → 停止录音"生成一条课堂记录
- 包含：录音音频 + 全文 ASR 文本 + 全文翻译 + 收藏知识点 + 语种 + 时长 + 日期
- 列表视图：日期 + 课程名（可自定义）+ 时长 + 收藏数 + 文本预览
- 详情视图：双语字幕流还原 + 音频同步播放 + 收藏点高亮
- 支持按课程名分组、按日期排序

#### 4.5.2 音频回放

- 播放时对应文字句子同步高亮（歌词效果）
- 点击任意句子跳转到对应音频位置
- 点击收藏标记直接跳到关键知识点位置
- 支持倍速播放（0.75x / 1x / 1.25x / 1.5x / 2x）

#### 4.5.3 导出

| 导出格式 | 内容 |
|---------|------|
| **Markdown** | 收藏知识点 + 标签分类，可直接导入 Notion/Obsidian |
| **TXT** | 全文双语对照文本 |
| **SRT** | 字幕格式（可用视频播放器加载） |
| **PDF** | 课程名 + 日期 + 全文 + 收藏标注 |

### 4.6 专业词典（P1）

针对学术场景，提供专业术语翻译优化：
- 按学科分类加载术语表（计算机/商学/医学/法律/工程等）
- 用户可自定义添加术语
- ASR 识别时优先匹配术语库中的词汇
- 翻译时术语保持一致性

## 5. 用户流程

### 5.1 首次使用流程

```
[启动App] → [选择模式：摄像头翻译 / 语音翻译]
    → [语音翻译模式]
    → [请求麦克风权限] → [允许/拒绝]

    → [提示试用：按住按钮说话]
    → [首次翻译完成] → [提示可切换持续聆听模式]
    → [提示登录后可保存记录] → [立即登录/稍后]
```

### 5.2 核心翻译流程

```
[进入语音翻译界面]
    ├── 默认按键说话模式
    ├── [按住录音键] → 麦克风采集 → 波形显示
    ├── 音频流 → ASR 引擎（云端/离线）
    ├── ASR 返回文本（流式） → 原文气泡实时更新
    ├── VAD 检测静音 ≥1.5s → 自动断句
    ├── 完整句子 → 翻译引擎
    ├── 译文返回 → 译文气泡弹出
    ├── 原文+译文加入对话列表
    └── 循环（持续聆听模式下自动继续）
```

## 6. 界面设计原则

### 6.1 设计理念

> **字幕优先（Subtitle-First Design）**：UI 设计模拟视频字幕体验。学生面对的是一个"实时双语字幕机"，关注点在文字内容而非操作界面。当前句醒目，历史句缓退，收藏一键完成。

### 6.2 布局规范

```

│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓   │  ← 音频波形条

│                                 │
│   过往句（可滚动回看）           │
│   … Industrial Revolution …    │  ← 原文 小字 灰色
│   … 工业革命始于英国…           │  ← 译文 小字 淡绿
│   ───────────────────────      │
│ ★ The steam engine played a    │  ← 当前句原文 大字 加粗
│   crucial role in this process.│
│ ★ 蒸汽机在这一过程中发挥了       │  ← 当前句译文 大字 绿色 ★已收藏
```

## 7. 非功能需求

### 7.1 性能指标

| 指标 | 目标值 |
|------|--------|
| **ASR 首字延迟** | < 300ms（云端）/ < 500ms（离线） |
| **翻译延迟** | < 500ms（在线）/ < 800ms（离线） |
| **端到端延迟** | < 1.5 秒（教授说话→学生看到译文） |
| **远场识别距离** | 1-5 米可识别（教室环境） |
| **VAD 断句准确率** | > 90% |
| **ASR 准确率** | > 95%（安静教室）/ > 85%（有背景噪音） |
| **续航** | 持续录音 ≥ 3 小时（满电） |
| **录音文件大小** | < 15MB / 小时 |

## 9. 数据指标

### 9.1 核心指标（北极星）

| 指标 | 定义 | 目标（上线后 3 个月） |
|------|------|---------------------|
| **日活录音次数** | 每天完成语音翻译的次数 | 日均 5 万+ |

### 9.2 埋点关键事件

## 11. 风险与应对

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|---------|
| ASR 在嘈杂环境准确率低 | 用户体验差 | 高 | 多麦克风波束成形 + 降噪算法；低置信度时标注提醒 |
| 流式识别延迟过高 | 实时性受损 | 中 | 本地端侧推理优先，云端 warm-connect 预连接 |
| 不同语种 VAD 效果差异大 | 断句不准 | 中 | 针对中日韩英等高频语种专项调参 |
| 长时间录音耗电/发热 | 用户抱怨 | 高 | VAD 静音时降低采样率；自适应帧率策略 |
| 录音文件存储空间过大 | 手机存储压力 | 低 | AAC 低码率压缩；只保留最近 30 天录音 |
| ASR 服务不可用时 | 核心功能不可用 | 低 | 离线 ASR 兜底；引导用户使用摄像头翻译模式 |
| 用户隐私顾虑（录音上传） | 法律/信任风险 | 中 | 提供"纯本地模式"选项；隐私政策透明；GDPR 合规 |
